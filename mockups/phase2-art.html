The illustration system

A commissioned, editorial geometric-organic set. Two stroke weights only (1.4 hairline, 2.6 primary), forest palette with a single clay whisper per piece, implied light from top-left, real layered depth behind key forms. A recurring cohesion motif runs through every piece: a soft connecting path and a gift cradling a heart. No faces, no sparkle. Each block below carries machine-readable ART:name markers so the SVG can be lifted verbatim into the live page.
